Sonic Study 001

Nine layers. Four minutes.
A composition you can change.

Interactive composition01–09 chaptersHeadphones recommended

This music is written in Sonic Pi. The code controls every note, instrument, and pause. Change a number or a sound, then press Run to hear your version.

01 / ExploreBegin with a small change

  1. Read the green comments beginning with #. They explain the music; commented code stays silent.
  2. Try a note, sample, instrument, or sleep value. Each chapter suggests a few supported experiments.
  3. Press Run, then Start audio. Use Restart to hear your next edit from the beginning. Reset restores the annotated original.

Start with your volume low. Each session ends after four minutes, with a short fade. Start another whenever you like.

02 / PlayThe composition

One continuous piece. Select lines and press Ctrl / or Command / to comment or uncomment them. Press Tab to leave the editor; indentation uses spaces.

About this browser version

The original notes, layers, and effects are preserved. This is a restricted Sonic Pi subset, so general Ruby and arbitrary JavaScript are unavailable. Browser audio can differ from desktop Sonic Pi. The isolated audio runtime is hosted separately on Cloudflare. Sound is generated in your browser; no continuously running audio server is needed.

Your code is sent only to the isolated audio engine in your browser. Edits are not saved when you leave. Download your version to keep it. Editor software notices · Audio licenses and corresponding source.
